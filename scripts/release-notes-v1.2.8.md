## PEEKS v1.2.8

### Highlights
- **월드컵 국가 전체 일정**: 홈 응원국 카드 또는 순위(🏆 WC → 조별)에서 **국가를 클릭**하면 6~7월 **전체 월드컵 일정**을 일정 탭에서 확인.
- **월드컵 맞대결 카드**: 응원국끼리 붙는 날 **홈 카드 1장**만 표시 (중복 제거).
- **일정 탭 개선 (v1.2.7+)**: NBA/KBO/축구 **스코어보드 폴백**, KBO 실제 경기일 필터, ESPN 스코어 `[object Object]` 수정, 순위 탭 기준 리그명(MLB·NBA 등).

### 월드컵 일정 보기
- **홈** → 월드컵 카드 클릭
- **순위 → WC → 조별 순위** → 국가 행 클릭 (순위·로고·★는 즐겨찾기)
- 일정 화면 **← 전체** 로 즐겨찾기 주간 일정으로 복귀

### Install
- `PEEKS-1.2.8-universal.dmg` — macOS (universal)
- `PEEKS-Setup-1.2.8.exe` — Windows installer
