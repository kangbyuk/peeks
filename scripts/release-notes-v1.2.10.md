## PEEKS v1.2.10

### 새 디자인 — 미니멀 글래스
- **반투명 블러 배경**: 창 뒤 바탕화면이 은은하게 비치는 macOS 글래스 스타일. (고스트 모드·투명도 조절·코더 모드에서는 기존처럼 동작)
- 흰색·회색 톤으로 색 정리, 카드·버튼 모서리 통일, 이모지 탭 → 깔끔한 글자 탭(밑줄 강조).
- 토글·저장 버튼·빈 화면·달력까지 같은 톤으로 통일.

### 달력 탭 — 일주일 한눈에
- 날짜를 하나씩 누르던 방식 → **월~일 7일을 날짜별로 한 화면에** 표시.
- 경기는 한 줄(시간 · 대진 · 스코어), 경기 없는 날은 "경기 없음" 한 줄, 오늘은 "오늘" 표시.
- 상단에 **"11월 2일 – 8일"** 주간 표시와 "이번 주" 버튼.

### 새 기능
- **경기 현지 시각 보기** (설정 → 기본 설정 → 경기 시간): 한국 시각(기본) / 경기 현지 시각. 현지 시각은 홈팀 구장 기준이며 PST·EST 같은 시간대가 함께 표시됩니다. KBO는 항상 한국 시각.
- **시즌 끝난 팀 카드 자동 숨김**: 다음 경기가 없고 마지막 경기 후 7일이 지난 팀은 홈에서 숨김. 맨 아래 "시즌이 끝난 팀 N개 · 보기"로 다시 펼칠 수 있고, 새 시즌 일정이 잡히면 자동으로 다시 나타납니다.
- **전체 경기 종목 순서 변경**: 🏀 ⚾ ⚽ 버튼을 드래그해서 순서 변경. 맨 앞 종목이 앱 시작 시 기본 선택됩니다.
- **순위표에서 내 팀 강조**: 응원 팀 행이 하이라이트됩니다.

### 개선·수정
- **전체 경기 날짜 표시**: 내일 경기가 오늘처럼 보이던 문제 수정 → "내일 오전 9:00"처럼 표시.
- **순위 표기**: "W7위" → **"서부 7위"**, MLB "NL 2위". 순위표 머리글 웨스턴/이스턴 → 서부/동부.
- **승률 표기**: 0.875 → **.875** (야구·농구 관례).
- 영어/한글이 섞여 있던 탭 이름 정리 (baseball, Soccer → 야구, 축구).
- **월드컵 메뉴 숨김**: 대회가 끝나 순위·팀 관리·전체 경기·달력에서 월드컵을 숨겼습니다. (다음 대회 때 다시 켭니다)
- 비시즌 MLB 일정 조회 시 오류 로그가 반복되던 문제 수정.

### Install
- `PEEKS-1.2.10-universal.dmg` — macOS (universal, Apple Silicon·Intel)
- `PEEKS-Setup-1.2.10.exe` — Windows installer

### macOS 설치 방법
1. 실행 중인 PEEKS를 종료합니다.
2. `PEEKS-1.2.10-universal.dmg`를 열고 **PEEKS**를 **Applications** 폴더로 드래그 → "대치" 선택.
3. 처음 실행 시 "확인되지 않은 개발자" 경고가 뜨면: Applications에서 PEEKS **우클릭 → 열기**, 또는 시스템 설정 → 개인정보 보호 및 보안 → **그래도 열기**.

즐겨찾기 팀·설정은 그대로 유지됩니다.
