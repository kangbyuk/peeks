## PEEKS v1.2.9

### Fixes
- **NBA 순위 — 현재 시즌 표시**: 10월 이후에도 지난 시즌(2025-26) 최종 순위가 보이던 문제 수정. 이제 2026-27 시즌 순위를 불러옵니다.
- **NBA 플레이오프 대진**: 새 시즌 개막 후 지난 시즌 플레이오프 대진이 남아 있던 문제 수정.
- **NBA 순위 탭 기본값**: 지난 봄에 선택한 "플레이오프" 탭이 새 시즌까지 고정되던 문제 수정. 시즌이 바뀌면 시기에 맞는 탭(정규시즌/플레이오프)으로 열립니다.
- MLB·축구·월드컵 순위도 새로고침·탭 진입 시 다시 불러옵니다.

### Install
- `PEEKS-1.2.9-universal.dmg` — macOS (universal, Apple Silicon·Intel)
- `PEEKS-Setup-1.2.9.exe` — Windows installer

### macOS 설치 방법
1. 실행 중인 PEEKS를 종료합니다 (메뉴 막대/Dock에서 종료).
2. `PEEKS-1.2.9-universal.dmg`를 열고 **PEEKS**를 **Applications** 폴더로 드래그 → "대치" 선택.
3. 처음 실행 시 "확인되지 않은 개발자" 경고가 뜨면: Applications에서 PEEKS **우클릭 → 열기**, 또는 시스템 설정 → 개인정보 보호 및 보안 → **그래도 열기**.

즐겨찾기 팀·설정은 그대로 유지됩니다.
