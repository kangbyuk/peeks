## PEEKS v1.2.11

### 수정
- **상단 바 정렬**: macOS 닫기·접기·확대 버튼과 PEEKS 로고·갱신 시간·아이콘의 세로 위치가 어긋나 있던 문제 수정 → 한 줄로 정렬. 헤더 높이도 조금 줄어 화면이 더 넓어졌습니다.

### Install
- `PEEKS-1.2.11-universal.dmg` — macOS (universal, Apple Silicon·Intel)
- `PEEKS-Setup-1.2.11.exe` — Windows installer

### macOS 설치 방법
1. 실행 중인 PEEKS를 종료합니다.
2. `PEEKS-1.2.11-universal.dmg`를 열고 **PEEKS**를 **Applications** 폴더로 드래그 → "대치" 선택.
3. 처음 실행 시 "확인되지 않은 개발자" 경고가 뜨면: Applications에서 PEEKS **우클릭 → 열기**, 또는 시스템 설정 → 개인정보 보호 및 보안 → **그래도 열기**.

즐겨찾기 팀·설정은 그대로 유지됩니다.
